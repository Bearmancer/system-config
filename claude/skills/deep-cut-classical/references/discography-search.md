# Discography search — research depth, not a lookup order

**Scope tier: cross-skill, genre-agnostic.** The entry→trace→verify method and the duration-verification rules apply to any composer, artist, or genre. `deep-cut-classical` owns this file today. A future genre-general or non-classical music skill points at this file by name. Classical-specific material (ban list, era rules, orchestral/chamber/vocal priority order) stays in this skill's own `SKILL.md` and `references/exclusions.md`.

"Find every recording of work X" or "what's the duration of Y" is a research task: identify candidates, trace each one to its underlying original session, cross-check from a second angle, then call it complete.

## Citation sources

Cite MusicBrainz, Discogs, Presto Classical, label websites, and print/label liner notes for metadata, credits, dates, and catalog facts. Streaming services (Spotify, Apple Music, Apple Classical, Amazon Music, Tidal, Deezer, Qobuz) serve as listen-to pointers for the user, at any stage of the research.

## Method: entry point → trace → verify

Every source below is a place to find _candidates_; each candidate gets traced before it counts.

### 1. Entry points — cast the net

Start with **MusicBrainz** (open metadata database — structured, MBID-citable, cross-referenced release/recording/work relationships) and **Discogs** (discography and pressing-variant detail, marketplace-verified catalog numbers). Query from more than one angle:

- Composer/work + performer or conductor
- Performer/conductor + label
- Catalog number, if one is already known
- Work title alone, filtered by era/orchestra, to catch entries the first query's phrasing missed

Different angles surface different pressings, reissues, and box-set appearances of the same underlying session — run at least two angles to treat a result set as complete.

### 2. Trace each candidate to its underlying session

Reissues, box-set compilations, and streaming-era repackagings routinely repress an existing session under a new catalog number, new cover art, or a new decade's remastering. For every candidate:

- Identify the original recording session (venue, dates if known, orchestra) — the session, not just the sleeve's release date.
- Check whether it's a **repress** of an already-identified session (same take, new packaging). State this explicitly: "all other listings are represses of [session]" is a real, useful finding.
- Where MusicBrainz/Discogs disagree or run thin on a given release, use **Presto Classical** (classical-specific retailer, strong on new-release and label-crossover detail) to fill the gap, then the **label's own website** as the tie-breaker — authoritative for its own catalog, cross-reference it last after the aggregators.

### 3. Verify before reporting complete

- State a source conflict on a date, catalog number, or session detail in one line.
- Before saying "N recordings exist," confirm each of the N traces to a genuinely distinct session.
- Name how far the research went — one query, one source, one page, or the full multi-angle sweep — alongside the result.

## Duration verification

A duration is a claim: cite two independent sources, cross-check the movement-breakdown sum, flag complete-vs-cut, state a range with names when recordings differ. Full worked rules: this skill's `SKILL.md` "Timing verification" section — that discipline applies to any composer or work.
