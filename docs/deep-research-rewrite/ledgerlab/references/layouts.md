# Layout picker

Pick ONE layout per lesson from the claim shape. Build once. Record the choice in the lesson header. Atlas: `docs/deep-research-rewrite/layouts.html`.

| Claim shape | Layout | Mode |
|---|---|---|
| one mechanism | concept page | learn |
| items with the same attributes | table-first | learn, rules |
| ordered procedure | step list | rules |
| dated events | timeline | learn |
| causal chain | cause-effect (diagram optional) | learn |
| conditions and outcomes | decision tree | rules |
| terms | glossary entries, auto-linked | all |
| status-bearing claims | claim cards | verify |
| any lesson | layered wrapper: answer, detail, sources | learn |
| quick reference | cheat sheet | rules |
| question-shaped topic | Q&A stack, sparingly | learn |

Layered wrapper is the default frame. Direct explanation only; no narrative.
