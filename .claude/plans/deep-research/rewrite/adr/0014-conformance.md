# Prose must conform to the ledger

- No voice rule. Reader-facing prose follows the role prompts only.
- Status labels appear only in verify cards, debate blocks and errata. Citations are inline links on source-naming words. Agent-internal text stays caveman-lite.
- Reader profile: India-aware global scope; prices in INR only when cost is the topic.
- Conformance gate: an extractor re-splits the final prose; any claim absent from the ledger fails the gate.
- Run record: one auto-written file per run (mode, models, surfaces, covered/failed sources, gate verdicts, diff). Replaces hand-written learning-records.
