# One layout per lesson, picked by the agent from claim shape

Lessons are direct explanation, not narrative. The Layout Atlas (12 layouts, published artifact) is a design-time contrast of every option. At run time the agent picks ONE layout from the claim shape using the Atlas picker rules and builds the page once. No multi-render, no layout judge. Layout choice is recorded in the lesson header. Rejected: rendering 2-3 or all 12 candidates per lesson (cost, not wanted).
