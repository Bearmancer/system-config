# Lawful acquisition; paraphrase + cite

No shadow libraries (Anna's Archive, LibGen, Z-Library). Surfaces: publisher PDFs, open access indexes, Internet Archive and Wayback snapshots, public-domain archives, FOSS fetch tools, the user's own library access. Paywalled/gated sources that no lawful surface reaches are logged failed-to-grab, never circumvented. Public pages paraphrase with page/URL citation; short attributed quotes only when wording matters.
