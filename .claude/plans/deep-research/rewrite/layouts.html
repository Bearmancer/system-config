1 · Concept page

definition → mechanism → edge cases
Fits: one mechanic, one idea
Weak at: many parallel items, long sequences

Printer goes offline

What it is. The computer can no longer reach the printer at the address it saved.

How it works. The computer stores the printer's IP address. The router can hand the printer a new IP when its lease expires. The saved address then points at nothing.

Edge cases.

  • Printer asleep: the first job may fail, the second succeeds.
  • Printer on a guest network: computer cannot see it at all.

2 · Glossary entries

1–3 lines, cross-linked
Fits: vocabulary, hover targets
Weak at: anything needing explanation or order

DHCP lease — time the router lends an IP address to a device. See IP address.

IP address — a device's network address. Changes when a lease is renewed on a new one.

SSID — the Wi-Fi network name. See Band.

Band — 2.4 GHz or 5 GHz radio range. Many printers join 2.4 GHz only.

3 · Q&A stack

plain questions, short answers
Fits: "what is / why does" topics
Weak at: ordering, tables, relationships between answers
Why does my printer say offline when it is on?
The computer's saved address no longer matches the printer's current one.
Does restarting the router fix it?
Sometimes. It forces new leases, which can break or repair the match.
Why only on some networks?
Printers that join only 2.4 GHz can't see a 5 GHz-only network name.

Short answer: the computer is looking at an old address.

Detail

The router renews addresses on a timer. When the printer gets a new one, the computer's saved port points at nothing.

Edge cases

Sleeping printers and guest networks produce the same message for different reasons.
