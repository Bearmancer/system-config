# wave-1 digests
- Tavily: answer-oriented search+extract+map+crawl+research, reranked chunks, credits per call type.
- Firecrawl: scrape/crawl/map/search/extract/monitor, flat 1cr/page, maxAge 0 for rigor.
- Exa: semantic index, highlights token-efficient, verticals company/people, agent_run async.
- Dappier: realtime search + recommendations only, no scrape/crawl, licensed feeds.
- AgentQL: single-URL NL structured extraction, SDK for auth/JS, per-call pricing.
