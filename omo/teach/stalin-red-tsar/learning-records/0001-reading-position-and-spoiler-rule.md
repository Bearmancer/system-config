# Reading position at entry, and the spoiler rule as a design constraint

Status: active

Evidence: the initial request itself (ch.14 explanation + "enumerate all characters" + the no-spoiler rule, which the user asked to be persisted globally).

Implications: lessons must state the reading position explicitly and stop there, including where the book teases ahead; a cast glossary anchored to the last chapter read is a required artifact, not a nice-to-have; retrieval practice (quizzes) works on chapter facts without reaching forward.
