# Evidence audit + four-tool verification pass; "unverified" becomes a tracked, first-class list

Status: active

The user asked for an audit of "things written that have no evidence", then for a final pass over only the still-unverified claims using all four MCPs in a fixed order (Firecrawl → Exa → Tavily → Firefox devtools). Four read-only audits produced ~90 findings across eight pages; four file-scoped fix agents applied them. The pattern that emerged and should persist: every page now separates **Verified** (a source that is not the video) from **source-claimed**, and every claim the video makes without a record keeps a visible "the video's account" label. The final tool pass then moved several items across that line — **Bailey's 1973 indictment and hung jury** (US v. Bailey, M.D. Fla. 1975), the **Directly Speaking** notarised transcripts and series numbers (VA-2160/VAL-2150), a documented **Amway Diamond Club in Hawaii** (early 1983) as distinct from the unrecorded kingpin confrontation, and **Ford-archive Amway material** (1965 Amway Sales Convention speech, NAID 4525846; an Aug 1975 White House press file mentioning Warren Rustand and Amway, NAID 1671500) — while one item flipped the other way: Manson **enrolled** the Carnegie course at Terminal Island in 1957 and **dropped out**, so "completed" had to be corrected everywhere.

Evidence: the four audit tables (unsourced / circular / over-labelled / contradicted, each with a minimal fix); the fix agents' change logs; the final-pass results (Exa: Bailey, Manson; Firecrawl: the Amquix transcript page; Tavily: *Netco, Inc. v. Dunn*, 194 S.W.3d 353 (Mo. 2006); Firefox devtools: the JS-driven NARA catalog); and the gate state (check_lesson exit 0 on all five lesson/reference pages, cast map strict geometry 0 defects, all internal links resolving).

Implications: run this audit + pass as a standing step when a chapter's pages are new, not only when the user asks. Carry the tool order inside every research subagent prompt. Keep the Gaps list live in both directions — resolved items (Bailey) must leave the gap list, and a found source must not be re-used to launder an unsupported neighbouring claim. Where the video's own unsupported numbers are load-bearing (the 2%/98% split, the $30m year), the pages say so rather than adopting a convenient figure.
